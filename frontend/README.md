# Amazon Product Scraper: Frontend

**Objective:** Interface for a simple app that scrapes Amazon product listings from the first page of search results for a given keyword.

---

### Documentation:

- Writen in: HTML, CSS, Vanilla JavaScript with Vite
- Upon user input, it sends a GET request with the query to the backend API and dynamically renders the returned data (title, image, rating, reviews, and product link) without storing or persisting any information.

---

### Run in the project main folder:

```bash
bun install:all
```

```bash
bun run dev
```

### Or for running individualy:

#### To install dependencies:

```bash
bun install
```

#### To run:

```bash
bun run dev
```

And make sure to run the backend API.

This project was created using `bun create vite` in create-vite v6.4.1. [Vite](https://vite.dev/).
